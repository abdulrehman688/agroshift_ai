# Zameen Design System

Back to [[Home]]. Related: [[UX Patterns]]

Zameen shows the farmer's land from above, with a dark sheet holding the decision, evidence and one main action.

## Color

| Role | Value |
|---|---|
| Background | `#10140D` |
| Surface | `#1A2015` |
| Accent surface | `#26301A` |
| Hairline | `#30362A` |
| Text | `#F3F5E8` |
| Secondary text | `#B9C0A8` |
| Accent | `#D8F36F` |
| Text on accent | `#172006` |
| Canal | `#6FB7C8` |

## Rules

- One bright element per screen and quiet surrounding UI
- 4dp spacing grid
- 48dp minimum touch target, 56dp or more for primary actions
- Sentence case, no hype copy, no emoji icons
- Status is never shown by color alone
- Arabic-script text uses zero letter spacing and generous line height
